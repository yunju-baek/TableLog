# Fish Audio 태블릿 앱 0.1.0

맥스튜디오에서 실행하는 Fish Audio S2 웹을 Android 앱으로 엽니다. **S2 모델을 태블릿에서 실행하는 앱은 아닙니다.** 서버가 켜져 있고 인터넷 연결이 필요합니다.

1. GitHub Releases의 `FishAudio-0.1.0.apk`를 설치합니다.
2. 앱을 열면 `https://yunju.work/fish-audio/`에 연결합니다.
3. 다른 서버는 상단 **서버 설정**에서 HTTPS 주소를 입력합니다. **맥스튜디오 선택**으로 기본 주소를 복원할 수 있습니다.

웹의 스트리밍·배치 합성, 참고 목소리 등록·선택, 목소리 학습 메뉴를 그대로 사용합니다. 참고 음성은 Android 파일 선택기에서 선택하며 M4A 자동 변환은 서버가 수행합니다. 생성 결과는 AAC/M4A입니다. **M4A 다운로드**는 브라우저에서 파일을 엽니다. 앱에 마이크 권한·전체 저장소 권한은 없습니다. 파일을 녹음하려면 별도의 녹음 앱을 사용합니다.

색상은 기존 웹의 코럴·보라·크림을 사용합니다. 가로·세로 회전으로 웹 화면을 다시 만들지 않지만, 앱 강제 종료·네트워크 변경·OS 절전 시 스트리밍이 끊길 수 있습니다. 장시간 백그라운드 재생 전용 서비스는 구현하지 않았습니다. 최신 Android System WebView가 필요합니다.

## 공개 APK와 보안 범위

APK에는 공개 서버 주소만 기본값으로 들어갑니다. 서버 비밀번호·관리자 키·SSH 키·기기 토큰·학습 음성·학습 모델은 포함하지 않습니다. URL을 숨기거나 난독화하는 방식에 의존하지 않습니다.

일반 TLS 검증을 사용하며 HTTP·인증서 오류 우회·JavaScript 네이티브 인터페이스·파일 URL 접근을 허용하지 않습니다. 앱 안의 네트워크 요청과 이동은 선택한 HTTPS 서비스 경로로 제한하며 타사 쿠키와 혼합 콘텐츠를 차단합니다. 설정·웹 저장소의 시스템 백업과 기기 이전도 제외합니다.

**Fish Audio 웹은 사용자의 요청에 따라 공개 상태입니다.** APK 역공학 여부와 무관하게 주소를 아는 사람은 현재 웹 기능을 사용할 수 있습니다. 서버 전체에 대한 침투 테스트나 취약점 부재를 보장한 결과는 아닙니다. 인증이 필요한 회의 녹음은 별도 TableLog 앱·서버 경로에서 처리합니다.

## 빌드

```sh
./gradlew :fishapp:testDebugUnitTest :fishapp:lintDebug :fishapp:assembleDebug
```

배포용 서명은 [Android 안내](README.md#빌드와-검증)를 따릅니다. 자동 테스트의 `liveFish=true`는 실제 서버에서 짧은 테스트 문장을 합성하므로 명시한 경우에만 실행합니다.
