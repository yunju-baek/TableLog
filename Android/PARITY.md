# Mac / Android 기능 비교

기준: 저장소의 Mac 2.8.0 `docs/USER_GUIDE.md`, Android 0.4.0. 아래 “지원”은 기능 구현 범위이며 음성 인식·LLM 결과 품질이나 처리 속도가 같다는 뜻이 아닙니다.

| 기능 | Mac | Android 0.4.0 |
| --- | --- | --- |
| 녹음 중 전사·자동 저장 | 지원 | 지원, 발화 구간 단위로 반영 |
| 종료 후 남은 전사 처리 | 자동 | 자동 |
| 일시정지·재개·녹음 복구 | 지원 | 지원, foreground service |
| 로컬 모델 선택 | Mac용 모델 | SenseVoice + Whisper Tiny/Base/Small/Medium INT8 |
| 맥스튜디오 서버 전사 | 별도 엔진 구성 | HTTPS로 짧은 구간 순차 전송 |
| 녹음 중 메모·시각·재생 이동 | 지원 | 지원 |
| 요약·종료 후 회의록 | 선택한 AI CLI | 서버 AI, 선택 시 약 2분 요약·종료 후 자동 생성 |
| 회의 내용 질문 | AI CLI | 서버 AI, 긴 기록은 관련 발언 선택과 범위 표시 |
| 녹취 교정·회의록 변경 | 검토·적용 | 검토·적용, 수정 전 이력 보관 |
| 실시간 AI 문맥 교정 | 지원 | 미지원, 수동 요청 교정만 지원 |
| 화자 이름 일괄 변경 | 지원 | 지원 |
| 발언 수정·분리·삭제·되돌리기 | 지원 | 지원, 이후 내용이 달라지면 오래된 되돌리기 차단 |
| 자동 화자 구분·목소리 등록/학습 | Mac 화자 엔진 | 미지원, 화자 수동 지정 |
| 기존 오디오 가져오기 | 지원 | M4A/AAC·MP3·WAV, 기기 디코더 지원 범위 |
| 참고 자료 | PDF·이미지·TXT·MD·URL·폴더 | TXT·MD 가져오기/편집만 지원 |
| 자료 선택·버전·폴더 동기화 | 지원 | 미지원 |
| 내보내기 | JSON·MD·M4A | JSON·MD·WAV·M4A(AAC) |
| 회의 화면 | 데스크톱 다중 영역 | 태블릿 목록/상세, 녹취·회의록·메모·자료 탭 |
| AI 실행 환경 | Codex·Claude·Gemini CLI | Mac 서버의 Qwen3.5 4B 4bit 또는 호환 HTTPS 서버 |

Android는 VAD가 발화 구간을 완성한 뒤 문장 단위로 전사합니다. Mac의 토큰 단위 스트리밍과 같은 지연 시간을 뜻하지 않습니다. 큰 모델에서 지연되면 음성을 파일에 계속 기록한 뒤 남은 전사를 이어갑니다.

기존 녹취를 바꾸는 재전사·교정은 검토 후 적용합니다. 처음 녹음하는 회의의 자동 전사는 바로 저장합니다. 자동 회의록은 직접 편집본과 별도 보관합니다.

5개 로컬 모델의 공개 한국어·영어 샘플, 녹음 종료 전 결과 반영, 마지막 구간 처리, 실제 HTTPS 전사·회의 AI를 검증했습니다. 실제 TB376FC의 장시간 속도·발열·배터리·한국어 회의 정확도는 측정하지 않았습니다. [검증 기록](VERIFICATION.md).
