# 테이블로그 사용법

테이블로그 2.9.0 기준입니다. 회의를 녹음하거나 음성 파일을 열고, 발언·화자·회의록·자료를 함께 편집할 수 있습니다.

## 1. 처음 준비하기

1. 앱을 실행하고 왼쪽에서 마이크를 선택합니다.
2. 상단 **AI 설정**에서 사용할 CLI를 선택합니다. **설치 확인 → 연결 테스트 → 적용** 순서로 확인합니다. 자세한 방법은 [AI CLI 연결 안내](AI_CLI_SETUP.md)에 있습니다.
3. **회의자료 추가**에서 PDF·이미지·TXT·Markdown·URL을 추가하거나 폴더를 연결합니다. 선택한 자료가 회의의 참고 맥락이 됩니다.
4. 회의 설정에서 제목·참석자와 회의록 생성 방식을 정합니다.

## 2. 녹음과 음성 파일 전사

- **녹음 시작**: 선택한 마이크로 녹음하고 발언을 표시합니다. 처음 실행할 때 macOS 마이크 권한을 허용합니다.
- **일시정지 / 녹음 재개** 또는 `⇧⌘P`: 마이크 입력을 멈추고 같은 회의에 이어서 녹음합니다. 입력 정리가 끝나면 재개 버튼이 활성화됩니다. 일시정지 상태에서도 **종료 · 저장**을 사용할 수 있습니다.
- **종료 · 저장**: 녹음을 마치고 전사와 음성을 저장합니다.
- **음성 파일 열기** 또는 `⌘O`: 기존 녹음 파일을 불러와 전사합니다. 진행률과 마지막 발언 정리 상태를 확인합니다.
- **JSON 저장** 또는 `⌘S`: 현재 전사 기록을 JSON으로 저장합니다.
- **음성 M4A**: 저장된 음성을 엽니다.

녹음 시간과 M4A는 실제 입력된 음성을 기준으로 이어집니다. 회의록의 회의 시작·종료 시각은 일시정지 시간을 포함합니다. 음성 파일 전사는 기존의 종료·저장 방식으로 조작합니다.

로컬 전사와 AI 교정 결과는 순차적으로 표시됩니다. 숫자·날짜·의미 변화가 포함된 교정은 차이 보기에서 원문과 비교합니다.

## 3. 회의 편집 채팅

오른쪽 창 상단의 **가− / 가+**로 글자 크기를 5단계로 조절합니다. 기본값은 이전 버전보다 한 단계 크며, 요약·답변·입력창·수정 전후 비교와 연결된 도움창에 함께 적용됩니다. 선택한 크기는 앱을 다시 실행해도 유지합니다.

오른쪽 **회의 편집**은 질문과 수정 요청을 함께 받습니다. 녹취, 화자 이름·배정, 회의록, 선택한 자료를 대상으로 요청할 수 있습니다.

예시:

- “실습 예산을 삼천만원으로 설명한 발언의 화자를 김교수로 바꿔 줘.”
- “화자 2의 이름을 이지현으로 바꿔 줘.”
- “이 녹취에서 ‘인공 지능’을 ‘인공지능’으로 통일해 줘.”
- “회의록을 결정 사항과 후속 과제 중심으로 정리해 줘.”
- “선택한 기획 자료에서 모집 인원을 30명에서 35명으로 수정해 줘.”
- “이번 회의에서 아직 확인할 사항을 알려 줘.”

요청 후 **변경 N개 · 전후 비교**를 펼쳐 확인하고 **변경 적용**을 누릅니다. 적용 직후 **되돌리기**로 복원할 수 있습니다. 후속 수정이나 회의 전환으로 내용이 달라지면 현재 내용을 기준으로 다시 요청합니다.

한 번의 수정안은 녹취·화자, 회의록, 자료 중 한 범위에 적용합니다. 범위가 넓은 작업은 대상을 나눠 요청하면 확인하기 편합니다. 긴 기록은 관련 구간을 우선 참조하며, 화면에 참조·제외 구간 수를 표시합니다.

회의록 수정은 별도 편집본에 저장합니다. 자동 생성 회의록과 편집본을 함께 보관합니다. 자료 수정은 새 버전으로 저장하며 가져온 원본은 보존합니다.

## 4. 발언과 화자를 직접 수정하기

화자 이름 옆의 작은 속성 표시에서 인식·교정 상태를 확인합니다. 발언 카드의 아이콘 위에 마우스를 두면 기능 이름이 표시됩니다.

| 위치·아이콘 | 기능 |
|---|---|
| 화자 이름 | 표시 이름 변경 |
| 연필 | 발언 분리·화자·문장 수정 |
| 양방향 화살표 | 인식 원문과 교정 결과 비교 |
| 사람 추가 | 해당 발언으로 목소리 학습 |
| 더보기 `…` | 인식 원문 보기·발언 삭제 |
| 목소리 연결 표시 | 등록 목소리 기반 이름 연결 확인 |

화자 배정은 음성·발언 맥락을 확인한 후 확정합니다. 목소리 학습에는 화자가 분명하고 잡음이 적은 구간을 사용합니다. 전사 화면의 **수동 교정 되돌리기**로 직전 직접 편집을 복원할 수 있습니다.

## 5. 요약·회의록·자료

**회의록 미리보기**와 **지난 회의 → 회의록**은 제목·목록·강조·표를 문서 서식으로 표시합니다. 본문을 선택해 복사하거나 `⌘F`로 내용을 찾을 수 있습니다. **MD 열기** 또는 **회의록 파일**로 저장한 Markdown 파일을 열 수 있습니다.

회의록 Markdown은 **회의 개요 → 핵심 요약 → 안건별 논의 → 결정 사항 → 후속 조치 → 확인할 사항**으로 구성합니다. 담당자와 기한이 확인된 후속 업무는 표로 정리하며, 추가 확인이 필요한 항목은 그대로 표시합니다.

전사문과 녹음 타임스탬프는 **전사** 화면에서 확인합니다. 회의록 개요에는 회의 일시를 **연-월-일 시:분~시:분**으로 표시합니다. 시작은 10분 단위로 절삭하고 마침은 10분 단위로 올림합니다. 예를 들어 10:52~11:45는 **10:50~11:50**으로 표시합니다. 정확히 11:40:00에 끝나면 11:40을 유지하며, 자정을 넘기면 종료 날짜도 표시합니다. 기존 기록의 종료 시각은 저장된 음성 길이·마지막 발언을 기준으로 계산합니다. 이 형식은 새로 생성하는 회의록에 적용됩니다. 실제 업무 일정은 발언 내용을 그대로 반영합니다. 자료 원문·분석 이력·도우미 기록은 앱의 해당 화면에서 확인합니다.

이전 회의는 **지난 회의 → 재가공본 만들기 → 회의록 생성**으로 새 형식의 회의록을 만들 수 있습니다. 기존 템플릿의 전사·근거 시각 항목도 새 생성 시 회의록 전용 형식으로 변환합니다.

재가공 화면에서는 **회의록 다시 생성**으로 현재 편집 내용을 반영합니다. 왼쪽 상태 문구에서 준비·작성 진행·저장 완료를 확인하고, **회의록 보기**로 결과를 엽니다. 오류가 발생하면 상태 문구에 원인을 표시하고 다시 생성을 활성화합니다. 직전 저장 결과는 **회의록 보기**에서 확인할 수 있습니다.

**회의 설정·참석자 → 회의록 자동 저장**에서 **녹음 종료 후 회의록 생성**을 켜면 녹음 종료 뒤 전사 갱신이 잠시 안정될 때 설정한 AI CLI로 회의록을 작성합니다. 녹음 중에도 갱신하려면 **녹음 중 주기적으로 갱신**을 추가로 켭니다. 기존 자동 생성 설정은 두 항목의 초기값으로 이어집니다. 재가공본은 내용을 검토한 뒤 직접 생성을 실행합니다.

전사 저장과 회의록 생성은 각각의 상태로 표시합니다. **회의록 생성 대기**에서는 저장된 전사를 확인하고 **회의록 생성**을 실행할 수 있습니다. Markdown 파일은 내용이 생성된 뒤 저장됩니다. 전사 편집 후에는 이전 회의록에 **최신 편집 내용 반영 대기**를 표시하며, 새 결과가 완성되면 갱신합니다.

**회의 요약·제안**을 펼치면 현재 안건, 요약, 결정 후보, 남은 질문을 확인할 수 있습니다. **지금 요약**은 현재 발언까지 분석하고, **자동 요약·제안**은 설정한 주기로 갱신합니다. 결정 후보는 근거 발언을 확인한 뒤 결정으로 표시합니다.

회의록 설정에서 **선택한 AI CLI**를 선택하면 AI 설정의 제공자를 사용합니다. 자료 분석·회의 도우미·화자 검토에도 같은 제공자를 사용합니다. Codex 요약 모델을 별도로 지정한 경우에는 Codex 선택 시 해당 모델을 요약에 사용합니다.

**회의자료·맥락 → 텍스트 추가**에서 안건·배경·메모를 붙여넣고 **추가**를 누릅니다. 제목을 생략하면 본문의 첫 줄을 사용합니다. 본문은 자료당 20만 자까지 저장하며, 줄바꿈과 원문을 보관합니다. **추가하고 계속**을 누르면 다음 자료를 이어서 입력할 수 있습니다.

텍스트·파일·URL 자료를 여러 개 함께 선택할 수 있습니다. 목록 위의 **이번 회의에 N개 선택**으로 반영 범위를 확인하고, 자료별 체크를 켜거나 끕니다. 텍스트는 저장 즉시 검색·참조에 사용합니다. AI 요약과 용어 추출은 **맥락 분석 재시도**로 실행합니다. 자료 용어의 음성 엔진 반영은 녹음 시작 시 적용됩니다.

오른쪽 AI 채팅에는 **“이 내용을 ‘회의 배경’ 자료로 추가해 줘: …”**, **“‘사업계획’과 ‘일정’ 자료의 마감일을 모두 11월 12일로 수정해 줘”**처럼 요청합니다. **변경 · 전후 비교**에서 새 자료와 수정 내용을 확인한 뒤 **변경 적용**을 누릅니다. 여러 자료의 추가·수정은 함께 저장되며, **되돌리기**로 해당 변경을 복원할 수 있습니다. 파일·URL 원본과 이전 자료 버전은 보관합니다. 녹취·회의록·자료는 종류별로 요청하고, 여러 자료는 한 요청에 담을 수 있습니다.

연결한 폴더는 15초마다 변경을 확인합니다. 새 자료와 수정 버전을 보관하고 이전 근거도 열람할 수 있습니다. 자료의 선택 여부로 현재 회의에 사용할 범위를 조절합니다.

## 6. 지난 회의와 저장 위치

목록의 **휴지통 아이콘** 또는 우클릭 메뉴의 **회의 삭제…**를 누르고 **삭제한 회의로 이동**을 선택하면 해당 항목을 삭제한 회의 목록에 보관합니다. 상단 **삭제한 회의**에서 내용을 확인하고 **목록으로 복원**할 수 있습니다. 취소를 누르면 현재 목록을 유지합니다.

회의록·전사·녹음·연결 자료는 원래 저장 위치에 보관합니다. 이 기능은 목록 정리에 사용하며 저장 공간은 유지됩니다. 같은 제목의 회의와 재가공본은 각각 관리합니다. 현재 녹음·저장 중인 회의는 작업 완료 후 삭제할 수 있습니다.

**지난 회의**에서 제목·날짜로 찾고 전사·회의록·자료·도우미 기록을 열람합니다. **재가공본 만들기**는 새로운 회의 사본을 만들며 원본 전사·회의록·M4A를 보존합니다.

기본 저장 위치는 `~/Documents/TableLog`입니다.

| 폴더 | 내용 |
|---|---|
| `Recordings` | 녹음 M4A |
| `Transcripts` | 전사 JSON |
| `Minutes` | 회의록과 편집본 |
| `MeetingMaterials` | 가져온 자료·추출문·버전 |
| `Assistant` | 도우미 기록과 편집 채팅 |
| `VoiceProfiles` | 등록 목소리·학습 자료 |
| `Diagnostics` | 처리 진단 기록 |

**저장 위치 설정**에서 경로를 변경할 수 있습니다. 변경은 다음 실행 때 적용되며 기존 자료 복사와 검증이 함께 진행됩니다.

## 7. 연결 오류가 있을 때

1. **AI 설정**에서 선택한 CLI와 실행 파일 경로를 확인합니다.
2. 해당 CLI에 터미널로 로그인합니다. [CLI별 안내](AI_CLI_SETUP.md)를 참고합니다.
3. 모델 ID를 비워 CLI 기본 모델로 연결 테스트를 진행합니다.
4. 사용 한도·로그인·모델 오류 메시지를 확인하고 해결한 뒤 다시 요청합니다.
5. 실시간 교정 오류는 **AI 교정 재시도**, 채팅 오류는 **현재 내용으로 다시 요청**을 사용합니다.

로컬 녹음·전사는 AI 요청과 독립적으로 진행됩니다. **실시간 문맥 교정 → 끔**을 선택하면 로컬 전사를 유지하면서 필요할 때 편집 채팅을 사용할 수 있습니다.
