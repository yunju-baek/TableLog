# 2.6.0 음성 엔진 업데이트

## 적용 내용

NeMo-Speech.cpp를 2026년 10월 2일 정식 배포된 **v0.2.0**으로 갱신했습니다. C++ 연결부, NeMo ASR 라이브러리, ggml의 CPU·BLAS·Metal 라이브러리를 함께 다시 빌드했습니다. 발언 경계 처리를 활성화하여 발언을 확정한 뒤에도 인식 문맥을 유지합니다.

NVIDIA ASR·화자 분리 GGUF는 공식 배포본의 SHA256과 일치하여 기존 파일을 재사용했습니다. 저장 위치, 회의 데이터 형식, 목소리 보관함과 특징값을 유지합니다. 새 전사에는 실행 엔진 revision을 기록하고, 음성·화자 설정 화면에 버전을 표시합니다.

## 화자 특징 추출기 비교

2026년 10월 21일, Apple M4 환경에서 sherpa-onnx v1.13.8의 CPU 2스레드 경로로 비교했습니다. 같은 사람에게 등록된 한국어 음성 5개, 총 25.60초를 사용했습니다. 앱 빌드와 전사 검사를 마친 대기 상태에서, 첫 실행으로 모델을 준비한 뒤 3회 측정한 중앙값입니다.

| 모델 | ONNX 크기 | 처리 시간 | 음성 길이 대비 처리 시간 |
|---|---:|---:|---:|
| TitaNet large | 101.4 MB | 0.573초 | 0.0224 |
| CAM++ zh/en advanced | 28.3 MB | 0.212초 | 0.0083 |
| ERes2NetV2 zh-cn | 71.4 MB | 1.385초 | 0.0541 |

CAM++는 이 표본에서 TitaNet 대비 약 2.7배 빠르게 처리했습니다. 모델마다 특징 공간과 유사도 분포가 달라서 유사도 수치는 모델별 보정 기준으로 사용합니다. 이번 표본은 한 사람으로 구성되어 화자 오인식률 산출에 필요한 다른 사람의 정답 자료가 부족합니다. 따라서 **앱의 기본 모델은 TitaNet으로 유지**합니다. CAM++와 ERes2NetV2는 비교용으로 별도 보관했습니다.

향후 교체 평가는 여러 화자가 등장하는 한국어 회의에서 사람별 정답, 오인식·미인식률, 처리 시간을 함께 측정합니다. 새 모델 적용 시 기존 녹음으로 특징값과 개인별 분류기·판정 기준을 다시 계산하고, 기존 모델의 프로필은 별도 복원본으로 보관합니다. 세 모델 모두 192차원이지만 특징 공간은 각각 다릅니다.

## 검증

- 공식 CTest 8개: 발언 경계 정책, 후처리, 디코더, 화자 상태, 실시간 전사 등 통과.
- 21.67초 한국어 합성 입력: 중간 화자 표시와 최종 전사 보존 통과.
- 24.47초 휴지 포함 입력: 여러 발언 경계와 새 세션 초기화 통과.
- 실제 한국어 회의 60초: 기본 긴 문맥에서 83개 단어·7개 확정 발언, 짧은 문맥에서 84개 단어·8개 확정 발언, 각각 578회 중간 화자 갱신 확인. 결과 정확도는 별도 정답 대조 범위입니다.
- 기본 긴 문맥(13)·긴 화자 기억 설정과 NVIDIA 공식 화자 프리셋 모두 통과.
- 편집·되돌리기·저장 호환성 검사 41개 통과.
- 기존 회의·회의록·목소리 파일 73개의 SHA256 동일 확인. 재실행한 앱에서 지난 회의 46건 표시 확인.
- 입력 길이·NaN 검사, 완료 반복 호출, 잘못된 용어 입력 후 결과 유지, 무음 세션, 한국어 용어 토크나이저 확인.

음성 및 개인별 특징 벡터는 로컬 검증 경로에서 처리했습니다. GitHub에는 코드와 집계 기록을 보관합니다.
