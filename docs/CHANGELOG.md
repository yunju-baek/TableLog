# 버전 기록

## 2.9.8 · 빌드 43

- AI CLI와 Qwen 전사는 운영체제의 자식 프로세스 종료 상태를 직접 수거해 완료 결과를 전달합니다.
- 실행 제한 시간과 취소를 같은 작업에서 확인합니다. 종료 요청에 시간이 걸리면 해당 작업의 프로세스 그룹을 정리하고 대기 중인 다음 작업으로 이어갑니다.
- 실행 실패·사용 한도·시간 초과 안내와 전사 초안 보존을 유지합니다. Qwen 재전사의 최대 실행 시간은 3시간입니다.

## 2.9.7 · 빌드 42

- 기본 창 크기를 1600×960으로 확대하고, 시작 화면부터 같은 크기를 사용합니다. 화면의 사용 가능 영역 안에서 여백을 두고 가운데 배치합니다.
- 창 크기는 해당 창이 생성될 때 한 번 적용합니다. 음성 엔진 준비 완료 시점이나 다른 창의 포커스에 관계없이 초기 크기를 적용하며, 이후 사용자가 조절한 크기를 유지합니다.

## 2.9.6 · 빌드 41

- 전사록의 추정·자동 연결 이름 옆에 **✓ 확정**, 화자 이름 입력창에 **이름 확정**을 추가했습니다. 해당 화자의 이름을 즉시 저장하며, 다른 화자의 입력 중인 이름은 유지합니다.
- 파일 전사와 녹음 종료 후 Qwen 재전사 중 **새 회의 녹음**을 시작할 수 있습니다. 이전 작업의 제목·화자·자료·결과 파일은 회의별로 유지합니다.
- 왼쪽 **이전 회의 처리**에서 진행 상황과 중지 버튼을 제공합니다. 완료된 결과는 **지난 회의**에서 확인합니다.
- Qwen은 한 번에 한 건씩 실행합니다. 파일 전사는 한 건으로 제한하고, 새 녹음의 입력 대기가 늘면 파일 처리를 잠시 양보합니다. 완료한 작업의 음성 엔진은 해제합니다.

## 2.9.5 · 빌드 40

- 지난 회의 목록·상세 기록 조회에 5초 제한을 적용했습니다. 파일 응답이 지연되면 경고와 함께 불러온 회의를 표시합니다.
- 창을 닫으면 조회 대기를 즉시 해제합니다. 파일 읽기 작업은 목록·상세 각각 최대 1개로 유지해 반복 조회 시 작업 누적을 제한합니다.
- 목록 갱신 중에는 기존에 불러온 회의를 유지합니다. 제한 시간 이후 도착한 진행 정보와 결과는 화면 갱신에서 제외합니다.
- 상세 기록의 파일 읽기와 캐시 검증을 전용 백그라운드 작업으로 옮겼습니다.

## 2.9.4 · 빌드 39

- 앱 시작 시 목소리 프로필·회의 자료·폴더 연결 기록·회의록 서식을 백그라운드에서 읽고 검증합니다. 파일 읽기 지연 중에도 시작 화면과 종료 동작을 처리합니다.
- 각 읽기 단계에 5초 제한을 적용했습니다. 지연 시 경고를 표시하고 다른 기능의 준비를 이어가며, 해당 원본 파일을 보호합니다.
- 제한 시간이 지난 읽기의 결과는 별도로 정리합니다. 읽기 실패 상태의 프로필·자료·서식 저장을 보호하고, 정상 파일의 기존 로딩 동작을 유지합니다.

## 2.9.3 · 빌드 38

- 긴 회의의 실시간 화면을 최근 발언 카드 60개부터 표시하고, **이전 발언 보기**로 60개씩 펼치도록 개선했습니다. 이전 내용을 읽는 중에는 해당 구간을 유지합니다.
- 발언 묶음 계산 결과를 재사용하고, 전사·화자·수동 편집이 바뀔 때 갱신합니다. 복사·저장·AI 편집·회의록 생성에는 전체 기록을 전달합니다.
- 표시 내용과 편집 대상이 같은 발언 카드는 화면 계산을 재사용합니다. 음량 막대는 하나의 그리기 영역에서 갱신해 반복 애니메이션 비용을 줄였습니다.
- 임시 저장소와 가상 발언 1,000개로 실제 화면 코드를 구동하는 성능 측정 도구를 추가했습니다. [측정 조건과 결과](PERFORMANCE_2.9.3.md)를 확인할 수 있습니다.

## 2.9.2 · 빌드 37

- 음량·녹음 시간·처리 대기 표시의 갱신을 전사 본문과 분리했습니다. 음량 표시는 초당 최대 8회, 녹음 시간은 초 단위로 갱신합니다.
- 실시간 전사 화면 갱신을 초당 최대 2회로 묶고, UI가 바쁜 동안 최신 표시 상태 한 개를 보관합니다. 음성 입력과 최종 전사 저장은 전체 데이터를 유지합니다.
- 같은 화자의 긴 발언을 짧은 화면 카드로 나누고, 큰 단일 발언에는 **전체 발언 보기**를 제공합니다. 원문·시간·화자와 편집 대상은 유지합니다.
- 전사 표시용 문단·표기 변환 결과를 메모리 한도 내에서 재사용하고, 주기적 보조 작업의 호출 간격을 조정했습니다.

## 2.9.1 · 빌드 36

- 채팅에서 회의 제목·목적·장소·예정 일시·전사 맥락·교정 용어를 수정하고 되돌릴 수 있습니다. 제목 변경은 앱 화면·저장 기록과 회의록 제목에 함께 반영합니다.
- 명확한 제목 변경 명령과 **도움말**은 앱에서 직접 처리합니다. 입력창의 **가능한 요청**에서 작업 예시를 확인합니다.
- AI 편집 입력창에서 **Enter로 전송**, **Shift+Enter로 줄바꿈**을 지원합니다. 한글 조합 중 Enter는 글자 입력을 확정하며, 기존 `⌘Enter` 전송도 유지합니다.
- AI 사용 한도를 감지하면 해당 제공자의 대기 요청과 자동 호출을 일시 중지하고, 앱을 다시 실행해도 상태를 유지합니다. **AI 설정 → 연결 확인 후 재개**가 성공하면 다시 사용할 수 있습니다.
- CLI가 사용 한도 오류 뒤에 계속 대기하는 경우 실행을 정리하고, 녹음·로컬 전사·저장 기능을 이어갑니다. 다른 AI를 선택하면 해당 제공자의 연결을 사용할 수 있습니다.
- 앱 종료 시 AI 작업을 취소하고 녹음·전사와 완료된 회의록을 보관합니다. 회의록 생성 대기는 지난 회의의 재가공·생성 기능으로 이어갑니다.

## 2.9.0 · 빌드 35

- AI 채팅에서 새 자료 추가와 여러 자료의 동시 수정을 제안·검토·적용할 수 있습니다.
- 일괄 적용·되돌리기와 원본·이전 버전 보존을 지원하며, 선택한 자료를 현재 회의 맥락과 저장 기록에 반영합니다.
